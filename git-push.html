git init:在当前目录初始化一个新的 Git 仓库，会在当前文件夹创建一个隐藏的 .git 子目录，这个目录存储所有版本控制信息，执行后，当前文件夹就变成了一个 Git 仓库
git add .(或者*):将文件更改添加到暂存区
git commit -m "first commit":将暂存区的内容永久保存到仓库历史中。
-m：message 的缩写，后面跟提交信息
"first commit":提交说明，描述这次更改的内容，每次 commit 都会生成一个唯一的 ID
git remote add origin https://github.com/Renxin21/start.git:添加远程仓库的地址,本地就知道代码要推送到哪个远程位置
git push -u origin main:将本地代码推送到远程仓库。
-u：--set-upstream 的缩写，建立本地分支和远程分支的关联
origin：远程仓库别名
